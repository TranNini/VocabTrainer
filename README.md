git Spanish Vocab Trainer

Currently only a command-line vocab trainer to practice Spanish and English vocabulary.


Feature:

Add new Spanish and English vocabulary
Save vocabulary locally
Quiz saved vocabulary
Randomized vocabulary order
Practice both Spanish → English and English → Spanish
Score at the end of the quiz


How it works:

Main menu options
1. Add new vocab
    Add the Spanish word or sentence first then translate in English.
    Type 'done' once finished to return to main menu.
2. Quiz
3. Exit

Project Structure:

Vocab.java - represents a vocabulary entry
VocabStore.java - handles storing and loading vocabulary
VocabApp.java - runs the application and handles user interaction
